# استقرار بات «رشد» روی دارکوب هم‌روش (console.hamravesh.com)

> این راهنما بر پایه‌ی اطلاعات عمومی هم‌روش نوشته شده. چون صفحه‌های مستندات برای ابزارهای خودکار بسته است، نام دقیق دکمه‌ها ممکن است کمی فرق کند. موارد تأییدنشده در بخش «از پشتیبانی بپرسید» آمده است.

## پیش‌نیازها
- توکن بات (از `@botfather`) و شناسه‌ی عددی مدیر (با `/myid`)
- حساب در `console.hamravesh.com`
- Git روی کامپیوتر (برای فرستادن پروژه). Docker لازم نیست.

## ۱) گذاشتن پروژه در یک مخزن Git خصوصی
یک مخزن **خصوصی** در هم‌گیت (GitLab خودِ هم‌روش) یا GitHub بسازید. محتوای پوشه‌ی `rosh_bot` را (بدون `.env` و `data`) در آن بگذارید:
```
cd rosh_bot
git init
git add .
git commit -m "rosh bot"
git branch -M main
git remote add origin آدرس_مخزن
git push -u origin main
```
فایل‌های `Dockerfile` و `.dockerignore` در پروژه هست و `.env` هرگز نباید به مخزن برود (در `.gitignore` هست).

## ۲) ساخت اپ در کنسول
۱. «ساخت اپ» ← روش **منبع گیت** ← اتصال به مخزن.
۲. آدرس مخزن، شاخه‌ی `main`، و مسیر داکرفایل: `./Dockerfile`
۳. ادامه به «تنظیمات اپ».

## ۳) تنظیمات اپ

**منابع (کم‌ترین مقدار کافی):** ۰٫۲۵ هسته، ۵۱۲ مگ رم. اگر کنسول مقدار کسری نداد: ۱ هسته و ۱ گیگ.

**دیسک (ضروری):** یک فضای ذخیره‌سازی با مسیر اتصال `/data` و حجم ۱۰ تا ۲۰ گیگ. بدون دیسک، دیتابیس و عکس‌ها با هر ری‌استارت پاک می‌شوند.

**تعداد نمونه (Replica): دقیقاً ۱.** دو نمونه هم‌زمان، پیام‌های بله را دوباره پردازش می‌کنند و روی یک دیتابیس می‌نویسند.

**متغیرهای محیطی:**
| نام | مقدار |
|---|---|
| `BALE_TOKEN` | توکن بات |
| `ADMIN_IDS` | شناسه‌ی عددی مدیران، با ویرگول |
| `DATA_DIR` | `/data` |
| `PANEL_ENABLE` | `1` |
| `PANEL_HOST` | `0.0.0.0` |
| `PANEL_PORT` | `8090` |
| `PANEL_SECURE_COOKIE` | `1` |
| `PANEL_TRUST_PROXY` | `1` |
| `PANEL_URL` | آدرس https اپ (بعد از گرفتن دامنه) |
| `SQLITE_JOURNAL` | `WAL` (اگر روی دیسک خطا داد: `DELETE`) |

**پورت و دامنه:** خود بات پورت لازم ندارد؛ فقط پنل وب روی `8090` است. پورت `8090` را باز کنید و دامنه‌ی رایگان با SSL بگیرید؛ آدرس را در `PANEL_URL` بگذارید و اپ را دوباره دیپلوی کنید.

## ۴) دیپلوی و آزمایش
۱. دیپلوی را بزنید و لاگ اپ را ببینید؛ باید پیام «بات «رشد» شروع به کار کرد» بیاید.
۲. در بله `/start` بزنید ← پنل مدیریت.
۳. یک دانش‌آموز تستی بسازید، سپس اپ را **ری‌استارت** کنید و ببینید دانش‌آموز هنوز هست. (آزمون ماندگاری دیسک)
۴. پنل وب: در بات «🌐 ورود به پنل وب» ← کد ← آدرس https اپ.

## ۵) به‌روزرسانی
تغییر را در Git پوش کنید؛ هم‌روش خودکار می‌سازد و مستقر می‌کند. بات چند ثانیه قطع می‌شود؛ ساعت کم‌تردد را انتخاب کنید. داده روی دیسک می‌ماند.

## ۶) پشتیبان‌گیری
- هم‌روش روزانه از دیسک اپ‌ها پشتیبان می‌گیرد (و به دیتاسنتر دیگر می‌برد).
- بات هم شبانه یک نسخه‌ی دیتابیس در `/data/backups` می‌سازد.
- هفته‌ای یک‌بار از پنل وب «اکسل کامل» و ZIP پاسخ‌ها را روی کامپیوتر خودتان ذخیره کنید.

## هزینه (از جدول قیمت هم‌روش، دیتاسنتر ایران)
هر هسته ۵۹۵٬۰۰۰، هر گیگ رم ۲۹۰٬۰۰۰، هر گیگ SSD ۱۶٬۵۰۰ تومان در ماه.
- حداقل (۰٫۲۵ هسته، ۵۱۲ مگ، ۱۰ گیگ): حدود ۴۵۸٬۷۵۰ تومان
- پیشنهادی (۰٫۵ هسته، ۱ گیگ، ۱۵ گیگ): حدود ۸۳۵٬۰۰۰ تومان
- اگر مقدار کسری ممکن نبود (۱ هسته، ۱ گیگ، ۱۰ گیگ): حدود ۱٬۰۵۰٬۰۰۰ تومان
- ترافیک داخلی: دانلود هر گیگ ۳٬۲۰۰ تومان، آپلود رایگان؛ مصرف بات چند گیگ در ماه است.

## از پشتیبانی بپرسید (پیش از پرداخت)
۱. آیا CPU و رم کسری (۰٫۲۵ و ۵۱۲ مگ) قابل انتخاب است؟
۲. اپ بدون پورت (فقط پردازش پس‌زمینه) مجاز است؟
۳. دیسک اپ با SQLite در حالت WAL مشکلی ندارد؟ (یا باید `SQLITE_JOURNAL=DELETE` بگذاریم)
۴. دریافت ایمیج پایه‌ی `python:3.12-slim` در بیلد کار می‌کند؟ (در غیر این صورت خط اول Dockerfile را عوض می‌کنیم)
۵. مقدار اعتبار اولیه‌ی رایگان و نیاز یا عدم نیاز به احراز هویت.
۶. حجم دیسک بعداً قابل افزایش است؟

## عیب‌یابی
- **لاگ می‌گوید network ConnectError:** اپ به `tapi.bale.ai` نمی‌رسد؛ از پشتیبانی بپرسید خروجی اینترنت اپ باز است.
- **با هر دیپلوی داده پاک می‌شود:** دیسک روی `/data` وصل نیست.
- **پیام‌ها دو بار پردازش می‌شود:** تعداد نمونه‌ها بیش از ۱ است.
- **پنل باز نمی‌شود:** پورت `8090` و `PANEL_ENABLE=1` را چک کنید.

## به‌روزرسانی از نسخه‌ی قبلی (دارای داده)
۱. تغییرها را در Git پوش کنید (هم‌روش خودکار می‌سازد). دیتابیس روی دیسک `/data` می‌ماند و بات هنگام شروع، خودش آن را ارتقا می‌دهد (ستون‌های پایه و امتیاز اضافه می‌شود؛ هیچ داده‌ای پاک نمی‌شود).
۲. قبل از پوش، از پنل وب «اکسل کامل» را بگیرید و اگر امکانش هست از دیسک اپ در کنسول پشتیبان بخواهید.
۳. **پورت پنل اکنون ۸۰۹۰ است:** در تنظیمات اپ، پورت را از ۸۰۸۰ به `8090` تغییر دهید و متغیر `PANEL_PORT=8090` بگذارید.
۴. متغیرهای تازه (اختیاری): `MAX_FILE_MB=15`، `EXTRA_STREAK_SIZE=5`، `EXTRA_STREAK_POINTS=10`، `BOOK_MAX_PAGES=300`.

## گروه نهمی‌ها روی هم‌روش
بات را به گروه اضافه کنید و داخل گروه `/setgroup` بفرستید. بات برای ارسال به گروه به خروجی اینترنت به `tapi.bale.ai` نیاز دارد (همان که برای دریافت پیام‌ها لازم است).
