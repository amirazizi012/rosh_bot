# ADR 0006: پایه‌ی هفتم؛ تکلیف بدون نشان و امتیاز

- **وضعیت:** پذیرفته‌شده
- **تاریخ:** ۱۴۰۵/۰۷/۲۹

## زمینه
پایه‌ی هفتم هم باید تکلیف ارسال کند، ولی مجموعه برای آن‌ها نشان و امتیاز نمی‌خواهد.

## تصمیم
- `HOMEWORK_GRADES = (6, 7)` و `GAMIFIED_GRADES = (6,)` در `app/rules.py`. همه‌ی امکانات تکلیف برای هر دو پایه است.
- نشان و امتیاز با `rules.gamified` در لایه‌ی قواعد قفل شده‌اند (نه فقط در رابط)، تا هیچ مسیری برای هفتم چیزی نسازد.
- مخاطب تکلیف با ستون `assignments.target_grade` (۶، ۷ یا ۰ برای هر دو). مقدار پیش‌فرض ۶ است تا تکالیف قبلی برای هفتمی‌ها نیایند.
- رابط هفتم: منوی بدون «نشان‌ها»، صفحه‌ی «پیشرفت من» با آمار تکلیف، و در دید مدیر دکمه‌ی نشان و امتیاز نمایش داده نمی‌شود.

## پیامدها
- تکلیف امتیازی برای هفتم عملاً یک تکلیف معمولی است (امتیازش ثبت نمی‌شود).
- اگر روزی نشان برای هفتم خواستید، فقط `GAMIFIED_GRADES` و منوی دانش‌آموز را عوض کنید.
- جدول نشان‌ها فقط ششمی‌ها را نشان می‌دهد (پیش‌تر نهمی‌ها هم با صفر دیده می‌شدند؛ اصلاح شد).
