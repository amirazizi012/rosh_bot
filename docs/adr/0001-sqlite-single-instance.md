# ADR 0001: SQLite با یک نمونه‌ی بات

- **وضعیت:** پذیرفته‌شده
- **تاریخ:** ۱۴۰۵/۰۷/۲۵

## زمینه
حدود ۴۰ تا ۸۰ دانش‌آموز، حدود ۴۰ تکلیف در سال، و چند مدیر. داده‌ها باید ماندگار و قابل پشتیبان‌گیری ساده باشند.

## تصمیم
دیتابیس SQLite در `data/rosh.db` و **فقط یک نمونه‌ی بات** (Replica=۱).

## پیامدها
- پشتیبان‌گیری فقط کپی یک فایل است (و `app/scheduler.py` هر شب یک نسخه می‌سازد).
- نیازی به سرور دیتابیس و Docker Compose نیست.
- اگر چند نمونه‌ی بات با یک توکن روشن باشند، هر پیام چند بار جواب داده می‌شود و داده‌ها در دیسک‌های جدا از هم فاصله می‌گیرند. به همین دلیل `/whoami` و هشدار در README اضافه شد.
- اگر روزی بیش از یک نمونه لازم شد، باید به PostgreSQL برویم؛ این تصمیم را در یک ADR تازه ثبت کنید.
