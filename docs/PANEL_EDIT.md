# راهنمای فعال‌سازی پنل وب و ویرایش از پنل

> وضعیت: **مرحله‌ی ۱ پیاده شد** (دانش‌آموزان و گروه‌ها؛ بررسی پاسخ، نشان و امتیاز). مرحله‌های بعد در انتها آمده است.
> تصمیم معماری: `docs/adr/0009-panel-write-actions.md` (بخشی از ADR 0003 را عوض می‌کند).

## الف) مراحل فعال‌سازی پنل روی همروش

۱. در تنظیمات اپ (متغیرهای محیطی) این‌ها را بگذارید:

| متغیر | مقدار |
|---|---|
| `PANEL_ENABLE` | `1` |
| `PANEL_HOST` | `0.0.0.0` |
| `PANEL_PORT` | `8090` |
| `PANEL_SECURE_COOKIE` | `1` (فقط وقتی با HTTPS باز می‌شود) |
| `PANEL_TRUST_PROXY` | `1` (پشت پروکسی همروش) |
| `PANEL_URL` | آدرس https اپ، بدون `/` آخر |
| `LATE_WINDOW_HOURS` | `96` |

۲. در تنظیمات شبکه‌ی اپ، پورت `8090` را باز کنید و دامنه/زیردامنه‌ی https را به آن وصل کنید (جزئیات: `deploy/HAMRAVESH.md`).
۳. اپ را دوباره دیپلوی کنید (Replica=۱ بماند).
۴. در بات: `/start` ← «🌐 ورود به پنل وب» ← کد ۸ رقمی ← در آدرس پنل واردش کنید. کد محدودیت زمانی ندارد و یک‌بار مصرف است. اگر `PANEL_PASSWORD` را در `.env` بگذارید، رمز ثابت هم هنگام ورود لازم است.
۵. بعد از ورود، بالای هر صفحه‌ی ویرایشی فرم‌ها فعال است. نشست ۱۲ ساعت می‌ماند.

**امنیت (چون پنل دیگر فقط‌خواندنی نیست):**
- هر فرم تغییر یک توکن CSRF مخصوص نشست دارد؛ درخواست بدون توکن یا با `Origin` غیرمجاز رد می‌شود.
- کوکی `HttpOnly` و `SameSite=Strict` (و با HTTPS: `Secure`) است.
- مدیر بودن کاربر هر بار دوباره بررسی می‌شود (اگر از مدیران حذف شود، تغییر ممکن نیست).
- هر تغییر در «گزارش فعالیت» با برچسب «(از پنل)» ثبت می‌شود.
- کد ورود را به کسی ندهید؛ هر کس نشست داشته باشد همه‌ی کارهای مدیر را می‌تواند بکند.

## ب) آنچه در مرحله‌ی ۱ از پنل قابل ویرایش است

| بخش | کارها |
|---|---|
| دانش‌آموزان (`/students`) | افزودن گروهی (هر خط `نام | @یوزرنیم | گروه`) به‌همراه پایه |
| صفحه‌ی هر دانش‌آموز (`/student/<id>`) | تغییر نام، یوزرنیم، فعال/غیرفعال، بازنشانی ورود، انتخاب گروه‌ها |
| گروه‌ها (`/groups`, `/group/<id>`) | ساخت، حذف، انتخاب اعضا |
| بررسی پاسخ (صفحه‌ی دانش‌آموز) | وضعیت هر تکلیف: به‌موقع / با تاخیر / ناقص (با توضیح) / ارسال‌نشده / بازگشت به خودکار |
| امتیاز و نشان (`/points` و صفحه‌ی دانش‌آموز ششمی) | تأیید/رد هر مورد، تأیید همه، تغییر دستی امتیاز، حذف نشان |

دانش‌آموز در همه‌ی این کارها مثل بات پیام می‌گیرد (مثلاً تأیید امتیاز یا ناقص‌شدن پاسخ)، چون پنل از همان توکن بات استفاده می‌کند.

## ج) مرحله‌های ۲ تا ۴ (انجام شد)
| بخش | کارها |
|---|---|
| تکالیف (`/assignments`) | ساخت تکلیف (الزامی / تمرین بیشتر / امتیازی)، مخاطب (همه، پایه، گروه‌های انتخابی)، مهلت (تاریخ شمسی یا «فردا ۲۱:۳۰»)، آپلود چند فایل ضمیمه و اطلاع به دانش‌آموزان |
| صفحه‌ی تکلیف (`/assignment/<id>` ← «مدیریت تکلیف») | ویرایش عنوان/متن/امتیاز، افزودن و حذف ضمیمه، تمدید برای همه یا یک نفر، عذر موجه، درخواست ارسال مجدد، یادآوری، لغو و فعال‌سازی دوباره |
| پیام‌ها (`/messages`) و صفحه‌ی دانش‌آموز | پیام (با پیوست فایل: عکس، PDF، آفیس…) به همه، یک پایه، یک گروه یا یک نفر؛ ثبت و ارسال بازخورد (با تکلیف یا بدون آن) |
| بازخوردها (`/feedback`) و بخش «بازخوردها» در صفحه‌ی هر دانش‌آموز | هر بازخورد با تاریخ و ساعت و وضعیت رسیدن به بله (رسید / نرسیده / نامعلوم برای ثبت‌های قدیمی) ذخیره می‌شود؛ خلاصه به تفکیک دانش‌آموز، تاریخچه‌ی کامل هر نفر و دکمه‌ی «ارسال دوباره» برای نرسیده‌ها |
| باشگاه کتابخوانی (`/books`) | ویرایش کتاب و صفحه‌ها، حذف گزارش، ارسال دوباره به گروه، انتخاب گروه بله از گروه‌هایی که بات دیده |
| رسیدها (`/receipts`) | دیدن رسیدهای واریزی دانش‌آموزان و «دریافت شد» (به دانش‌آموز خبر می‌رود) |
| مدیران (`/admins`) | افزودن و حذف مدیر (مدیران `ADMIN_IDS` و خودِ مدیر حذف نمی‌شوند) |

آپلود: فرم‌ها `multipart` هستند؛ سقف هر فایل `MAX_FILE_MB`، حداکثر ۱۰ فایل، و فقط عکس/PDF/Office/متن/zip/mp3/mp4 پذیرفته می‌شود.

## د) معماری
- `app/actions.py`: لایه‌ی عمل‌ها؛ هر تابع `(ok, پیام)` برمی‌گرداند و هیچ HTML یا دکمه‌ی بله نمی‌سازد.
- `app/panel.py`: فقط مسیرهای `POST /act/<نام>` را می‌پذیرد، پیش از اجرا نشست، مدیر بودن، CSRF و Origin را چک می‌کند و با ریدایرکت (۳۰۳) به صفحه برمی‌گرداند؛ خواندن همچنان با اتصال `mode=ro` است و فقط برای عمل‌ها یک اتصال نوشتنی کوتاه‌عمر باز می‌شود.
- `app/panel_ui.py`: فرم‌ها (`{{CSRF}}` هنگام ارسال با توکن نشست جایگزین می‌شود).
- هم‌زمانی: بات و پنل هر دو روی یک SQLite (WAL) می‌نویسند؛ هر نوشتن کوتاه است و با `timeout` ۱۰ ثانیه انجام می‌شود.
