# بات تکالیف «مجموعه تربیتی، آموزشی رشد» (اپ بله)

بات ثبت و دریافت تکالیف پایه ششم: دانش‌آموز با کد شخصی وارد می‌شود، تکلیف را می‌بیند و پاسخ را با عکس یا PDF می‌فرستد؛ مدیر مهلت تعیین می‌کند، گزارش می‌گیرد و بازخورد می‌دهد.

## امکانات فاز ۱ تا ۳ (ساخته و آزمایش شده)

| بخش | توضیح |
|---|---|
| ورود | کد ۶ رقمی شخصی؛ قفل ۱۰ دقیقه‌ای بعد از ۵ بار اشتباه؛ بازنشانی کد توسط مدیر |
| تکلیف | عنوان، متن، عکس/فایل ضمیمه، نوع (الزامی / اختیاری / امتیازی)، مخاطب (همه یا گروه‌ها) |
| مهلت | تاریخ شمسی و ساعت ایران؛ تاخیر مجاز ۲۰ دقیقه؛ ارسال با تاخیر تا ۲۴ ساعت با ثبت دقیق «ساعت و دقیقه» تاخیر؛ بعد از ۲۴ ساعت بسته |
| ارسال | چند عکس/PDF + «ارسال نهایی»؛ جایگزینی پاسخ تا قبل از مهلت |
| مدیر | ویرایش، تمدید برای همه یا یک نفر، عذر موجه، درخواست ارسال مجدد (وضعیت زمانی ارسال اول حفظ می‌شود)، لغو تکلیف |
| نشان‌ها | هر ۶ تکلیف الزامی پشت‌سرهم و به‌موقع = یک نشان؛ تاخیر یا ارسال‌نشدن شمارنده را صفر می‌کند؛ عذر موجه نادیده گرفته می‌شود؛ نشان‌های خودکار دیگر (اولین قدم، پیشگام، ستاره‌ی امتیازی، کنجکاو) و نشان دستی |
| گزارش | خلاصه‌ی کلاس، گزارش فردی، اکسل کامل (RTL)، آخرین ارسال‌ها، جدول نشان‌ها |
| دانلود | ZIP همه‌ی پاسخ‌های یک تکلیف یا یک دانش‌آموز |
| ارتباط | پیام همگانی (همه یا گروه)، بازخورد به هر فرد، یادآوری خودکار ۳ ساعت مانده به مهلت |
| ایمنی | پشتیبان روزانه‌ی دیتابیس (۱۴ نسخه)، ثبت همه‌ی کارهای مدیر (audit) |

**فاز ۴ (ساخته شد):** پنل وب فقط‌خواندنی؛ جزئیات در بخش «پنل وب» پایین.

**فازهای بعدی:** اتصال به کارنامه، آزمون تستی.

## راه‌اندازی

### ۱) ساخت بات در بله
در بله با `@botfather` یک بات بسازید و **توکن** را بردارید. عکس و نام بات را همان‌جا بگذارید (لوگوی رشد). توکن را برای هیچ‌کس نفرستید و در چت ننویسید.

### ۲) سرور (لینوکس، اوبونتو)
```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo useradd -m -s /bin/bash rosh
sudo mkdir -p /opt/rosh_bot && sudo chown rosh:rosh /opt/rosh_bot
# فایل‌های پروژه را در /opt/rosh_bot بگذارید، سپس:
sudo -u rosh bash -c 'cd /opt/rosh_bot && python3 -m venv venv && venv/bin/pip install -r requirements.txt'
```
اگر `pip` به PyPI نرسید، از یک mirror ایرانیِ معتبر با گزینه‌ی `-i` استفاده کنید.

### ۳) تنظیمات
```bash
cd /opt/rosh_bot && cp .env.example .env && nano .env     # BALE_TOKEN و ADMIN_IDS
chmod 600 .env
```
شناسه‌ی عددی مدیر: هر کس در بات `/myid` را بفرستد، شناسه‌اش را می‌گیرد. شناسه‌ها را (جدا شده با ویرگول) در `ADMIN_IDS` بگذارید. بعداً هم مدیر جدید از «⚙ مدیران» اضافه می‌شود.

### ۴) اجرا
آزمایش دستی: `venv/bin/python -m app.main`  
اجرای دائمی:
```bash
sudo cp deploy/rosh-bot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now rosh-bot
sudo journalctl -u rosh-bot -f      # دیدن لاگ
```

### ۵) لوگو (اختیاری)
فایل `assets/logo.png` را بگذارید؛ در پیام خوشامدگویی نمایش داده می‌شود.

## اولین استفاده
1. مدیر `/start` می‌زند ← «👥 دانش‌آموزان» ← «➕ افزودن»: اسم‌ها را (هر نفر یک خط، اختیاری `نام | گروه`) می‌فرستد و کدها را می‌گیرد.
2. هر کد را فقط به خود همان دانش‌آموز بدهید.
3. «📝 تکلیف جدید» ← عنوان، متن/عکس، نوع، مخاطب، مهلت ← انتشار.

## پشتیبان‌گیری
همه‌چیز در پوشه‌ی `data/` است: `rosh.db` + `assignments/` + `submissions/`. هر شب یک نسخه از دیتابیس در `data/backups/` ساخته می‌شود؛ پوشه‌ی `data/` را هفتگی جای دیگری هم کپی کنید.

## نکات امنیت و حریم خصوصی
- فقط نام، گروه و شناسه‌ی بله ذخیره می‌شود. پاسخ‌ها فقط برای مدیران قابل مشاهده است.
- کد ورود محرمانه است؛ هر کد فقط روی یک حساب فعال می‌شود.
- فایل `.env` را در هیچ مخزن یا چتی نگذارید.

## آزمایش
```bash
venv/bin/python tests/test_rules.py && venv/bin/python tests/test_flow.py && venv/bin/python tests/test_panel.py
```

## اولین آزمایش با بله‌ی واقعی (چک‌لیست)
این پروژه با بله‌ی جعلی کامل آزمایش شده، اما با سرور واقعی بله روی سرور شما باید یک‌بار چک شود:
1. `/start` و `/myid` جواب می‌دهد؟
2. دکمه‌ها کار می‌کنند و بعد از لمس، پیام ویرایش می‌شود (اگر ویرایش پشتیبانی نشود، خودکار پیام تازه می‌آید).
3. عکس و PDF از دانش‌آموز دریافت و ذخیره می‌شود؟
4. بات عکس تکلیف را برای دانش‌آموز و ZIP/اکسل را برای مدیر می‌فرستد؟
5. اگر هرکدام خطا داد، لاگ (`journalctl`) را برای اصلاح بفرستید.

## اجرای دائمی روی ویندوز (بدون سرور)
- `start_bot.bat` را اجرا کنید: بات را بالا می‌آورد و اگر قطع شد، بعد از ۱۰ ثانیه دوباره راه می‌اندازد.
- برای اجرا با روشن‌شدن سیستم: در Task Scheduler یک Task بسازید (Trigger: At log on، Action: همین فایل).
- خواب سیستم را خاموش کنید: Settings ← System ← Power ← Sleep = Never.
- `backup_data.bat` پوشه‌ی data را در `rosh_backup` کپی می‌کند؛ هفتگی اجرا کنید و نسخه را روی فلش یا Drive هم بگذارید.

## پنل وب فقط‌خواندنی (فاز ۴)

یک وب‌سایت فارسی و راست‌چین برای مدیران که همه‌چیز را **فقط نشان می‌دهد** و هیچ چیزی را تغییر نمی‌دهد.

**صفحه‌ها:** داشبورد (آمار روز، مهلت‌های پیش‌رو، نیازمند پیگیری، وضعیت همه‌ی دانش‌آموزان) | دانش‌آموزان و گزارش کامل هر نفر | تکالیف و وضعیت هر تکلیف با عکس پاسخ‌ها | نشان‌ها | بازخوردها | گزارش فعالیت مدیران | دانلود اکسل کامل و ZIP پاسخ‌ها.

### اجرا (کنار بات)
```
python -m app.panel          # ویندوز: start_panel.bat را اجرا کنید
```
سپس در مرورگر: `http://localhost:8090` . پنل یک فرایند جداست؛ بات هم باید یک‌بار اجرا شده باشد (تا دیتابیس ساخته شود).

### ورود (بدون رمز عبور)
۱. در بات بله: پنل مدیریت ← «🌐 ورود به پنل وب»
۲. کد ۸ رقمی را در صفحه‌ی ورود پنل بزنید. کد ۵ دقیقه اعتبار دارد و فقط یک‌بار قابل استفاده است. نشست ۱۲ ساعت باقی می‌ماند.

### چرا امن است
- پنل دیتابیس را فقط‌خواندنی باز می‌کند (حتی با باگ هم نمی‌تواند چیزی بنویسد) و هر درخواست غیر GET را رد می‌کند.
- کد ورود به‌صورت هش ذخیره می‌شود؛ بعد از ۵ تلاش ناموفق، ۱۰ دقیقه قفل می‌شود.
- کوکی `HttpOnly` و `SameSite=Strict` است؛ فایل‌ها فقط از داخل پوشه‌ی `data` سرو می‌شوند؛ همه‌ی متن‌ها escape می‌شوند.
- به‌صورت پیش‌فرض فقط روی همین سیستم (`127.0.0.1`) گوش می‌دهد.

### قرار دادن روی اینترنت (روی سرور)
فقط با HTTPS. فایل `deploy/Caddyfile.example` را ببینید (Caddy گواهی را خودکار می‌گیرد)، سپس در `.env`:
```
PANEL_URL=https://panel.example.ir
PANEL_SECURE_COOKIE=1
PANEL_TRUST_PROXY=1
```
سرویس دائمی: `deploy/rosh-panel.service` (مثل سرویس بات نصب می‌شود).
فونت: Vazirmatn (مجوز OFL؛ در `assets/`). اگر `assets/logo.png` بگذارید، در هدر پنل نمایش داده می‌شود.

## نصب سریع روی سرور اوبونتو (اسکریپت آماده)
۱. فایل ZIP را روی سرور بگذارید: `scp rosh-bale-bot.zip root@IP:/root/`
۲. روی سرور: `unzip rosh-bale-bot.zip && bash rosh_bot/deploy/install.sh`
۳. توکن بات و شناسه‌ی مدیران را وارد کنید؛ اسکریپت همه‌چیز را نصب و بات را اجرا می‌کند.
۴. بررسی: `systemctl status rosh-bot` و `journalctl -u rosh-bot -f`

### دیدن پنل وب بدون دامنه و HTTPS (تونل SSH)
روی سرور: `systemctl enable --now rosh-panel` ؛ روی کامپیوتر خودتان:
```
ssh -L 8090:127.0.0.1:8090 root@IP
```
و در مرورگر: `http://localhost:8090` (تا وقتی پنجره‌ی SSH باز است کار می‌کند).

### پشتیبان‌گیری از سرور روی کامپیوتر خودتان
`scp -r root@IP:/opt/rosh_bot/data ./rosh_backup`

## استقرار روی دارکوب هم‌روش (کانتینر)
فایل‌های `Dockerfile` و `.dockerignore` آماده است و پنل وب با `PANEL_ENABLE=1` داخل همان اپ اجرا می‌شود. راهنمای کامل: `deploy/HAMRAVESH.md`.

# نسخه‌ی پایه‌ی ششم و نهم (به‌روزرسانی)

## جداسازی پایه‌ها
هر دانش‌آموز یک «پایه» دارد (ششم یا نهم). مدیر موقع «➕ افزودن دانش‌آموز» پایه را انتخاب می‌کند؛ دانش‌آموزان قبلی همه «ششم» می‌مانند.
- **ششمی‌ها:** تکالیف، نشان‌ها و امتیاز.
- **نهمی‌ها:** فقط «📖 باشگاه کتابخوانی». هیچ تکلیف، نشان یا امتیازی ندارند.
- **مدیران:** به همه چیز دسترسی دارند. پیام همگانی هم می‌تواند فقط برای یک پایه ارسال شود.

## باشگاه کتابخوانی (پایه‌ی نهم)
مراحل دانش‌آموز: انتخاب «دو روز» (۶ جفت‌روز اخیر یا تاریخ دلخواه) ← نام کتاب (یا دکمه‌ی کتاب قبلی) ← از صفحه ← تا صفحه ← پیش‌نمایش ← «ثبت نهایی». نام را بات از ثبت‌نام برمی‌دارد.

گزارش همان لحظه در گروه بله ارسال می‌شود، با همین قالب:
```
نام: *مهدی‌یار ...*
گزارش روز: *دوشنبه و سه‌شنبه ۱۳ و ۱۴ مهر*
نام کتاب: *اسطوره های موازی*
از صفحه *۴۵۱* تا صفحه *۴۷۰* *(۲۰ صفحه)*
```
قواعد: برای هر جفت‌روز یک گزارش؛ «تا صفحه» کمتر از «از صفحه» نمی‌شود؛ سقف هر گزارش ۳۰۰ صفحه (`BOOK_MAX_PAGES`)؛ حداکثر ۴۵ روز گذشته (`BOOK_MAX_DAYS_BACK`). ویرایش و حذف فقط با مدیر است.

### وصل کردن گروه
۱. بات را به گروه نهمی‌ها اضافه کنید (فقط عضو کافی است).
۲. یکی از مدیران داخل همان گروه بنویسد: `/setgroup` ؛ یا در بات: پنل مدیریت ← باشگاه کتابخوانی ← «👥 انتخاب گروه نهمی‌ها».
۳. اگر ارسال به گروه شکست بخورد، گزارش ثبت می‌شود و به مدیر اطلاع می‌رسد؛ بعد از درست‌کردن گروه «🔁 ارسال مجدد به گروه» را بزنید.

### گزارش مدیر
در بات (📖 باشگاه کتابخوانی) و در پنل وب (صفحه‌ی «باشگاه کتابخوانی»): تعداد گزارش و صفحه‌ی هر نفر، کتاب‌ها، نمودار هفتگی، فیلتر ۷/۳۰/۹۰ روز، و اکسل. بدون رتبه‌بندی (ترتیب الفبایی).

## امتیاز (پایه‌ی ششم)
- **تکلیف امتیازی:** مدیر هنگام ساخت، امتیاز را مشخص می‌کند. بعد از ارسال دانش‌آموز، امتیاز «در انتظار تأیید» می‌ماند.
- **نشان کوشا:** هر ۵ تکلیف اختیاری/امتیازی پشت‌سرهم و به‌موقع = یک نشان و ۱۰ امتیاز (`EXTRA_STREAK_SIZE` و `EXTRA_STREAK_POINTS`)؛ آن هم بعد از تأیید مدیر حساب می‌شود.
- **تأیید:** پنل مدیریت ← «⭐ تأیید امتیازها» (تأیید یکی، رد یکی یا تأیید همه).
- **تغییر دستی:** صفحه‌ی دانش‌آموز ← «⭐ امتیاز» ← «➕/➖» (مثلاً `+5 مشارکت عالی`)؛ بدون نیاز به تأیید و با ثبت در تاریخچه.
- **نشان‌ها:** صفحه‌ی دانش‌آموز ← «🏅 مدیریت نشان‌ها»: افزودن، ویرایش عنوان و حذف. نشان خودکارِ حذف‌شده دوباره خودکار داده نمی‌شود.
- هر دانش‌آموز فقط امتیاز خودش را می‌بیند.

## تغییرهای دیگر
- پنل وب روی پورت **۸۰۹۰** است (`PANEL_PORT`).
- سقف حجم هر فایل ۱۵ مگابایت (`MAX_FILE_MB`).
- دیتابیس قدیمی خودکار ارتقا می‌یابد (چیزی پاک نمی‌شود). بعد از به‌روزرسانی، **اول بات را اجرا کنید** و بعد پنل را.

## نکات مستندات بله که در طراحی رعایت شد
- **پررنگ‌کردن:** `*متن*` با فاصله پیش و پس از ستاره‌ها؛ نویسه‌های `* _ [ ]` از متن کاربر حذف می‌شود تا پیام به‌هم نریزد.
- **ویرایش پیام:** مستندات بله فعلاً ویرایش پیام‌های دارای دکمه‌ی inline را پشتیبانی نمی‌کند؛ بات در این حالت پیام قبلی را پاک و پیام تازه می‌فرستد.
- **حجم:** دریافت فایل تا ۲۰ مگابایت؛ ارسال عکس تا ۱۰ مگابایت (بزرگ‌تر به‌صورت فایل می‌رود) و فایل تا ۵۰ مگابایت (بسته‌های ZIP زیر ۴۰ مگابایت ساخته می‌شود).
- **دریافت پیام:** اگر سرور بله پاسخ long-poll را فوری و خالی بدهد، بات هر ثانیه یک‌بار می‌پرسد تا فشار نیاورد.

## چک‌لیست آزمایش با بله‌ی واقعی (موارد تازه)
۱. گروه نهمی‌ها: `/setgroup` در گروه کار می‌کند؟ بات پیام‌های گروه (دست‌کم دستورها) را دریافت می‌کند؟
۲. پیام گروه: مقدارها **پررنگ** نمایش داده می‌شوند؟ (اگر نه، مستندات/نسخه‌ی بله را بفرستید تا قالب را اصلاح کنم.)
۳. یک دانش‌آموز نهمی بسازید و یک گزارش کامل ثبت کنید؛ در گروه ببینید.
۴. یک تکلیف امتیازی با امتیاز بسازید ← ارسال ← تأیید مدیر ← دیدن امتیاز در بات ششمی.
۵. فایل بزرگ‌تر از ۱۵ مگابایت رد می‌شود؟

## اگر هر پیام چند بار جواب داده شد
یعنی **چند نمونه‌ی بات هم‌زمان با همین توکن روشن‌اند** (هر کدام جداگانه به هر پیام جواب می‌دهد). دستور `/whoami` (فقط مدیر) را بفرستید: هر نمونه با نام خودش جواب می‌دهد. نمونه‌های اضافه را خاموش کنید (کامپیوتر خودتان، `start_bot.bat`، Task Scheduler، تعداد Replica در هم‌روش باید ۱ باشد). راه قطعی: در `@botfather` توکن جدید بگیرید؛ همه‌ی نمونه‌های قدیمی از کار می‌افتند و توکن جدید را فقط در یک جا بگذارید.

# ورود با یوزرنیم بله و ویرایش پاسخ (به‌روزرسانی)

## ورود با یوزرنیم (به‌جای کد ۶ رقمی)
- مدیر یوزرنیم بله‌ی هر دانش‌آموز را ثبت می‌کند. دانش‌آموز بات را استارت می‌کند؛ اگر یوزرنیم‌اش در فهرست باشد، **خودکار وارد می‌شود** (بدون کد).
- **افزودن دانش‌آموز:** «👥 دانش‌آموزان ← ➕ افزودن»، هر خط: `نام | @یوزرنیم` (اختیاری، سوم: `| گروه`). مثال: `علی رضایی | @ali_01`
- **دانش‌آموزان فعلی:** «📝 ثبت گروهی یوزرنیم»، هر خط: `نام دقیق | @یوزرنیم`. یا از صفحه‌ی هر دانش‌آموز «🆔 یوزرنیم بله».
- **یوزرنیم دانش‌آموزانی که الان وارد بات هستند خودکار ثبت می‌شود:** هنگام اولین پیام یا دکمه‌ای که بعد از به‌روزرسانی می‌زنند (اگر یوزرنیم داشته باشند و تکراری نباشد). آن‌ها بدون هیچ کاری وارد می‌مانند.
- **ورود فقط یک‌بار به یک حساب بسته می‌شود** (شناسه‌ی حساب ثبت می‌شود، نه یوزرنیم). بعد از آن، عوض‌کردن یوزرنیم در بله ورود را خراب نمی‌کند و کس دیگری هم با آن یوزرنیم وارد نمی‌شود؛ تلاش حساب دیگر رد می‌شود و به مدیر هشدار می‌رسد.
- **تغییر گوشی/حساب:** از صفحه‌ی دانش‌آموز «🔓 بازنشانی ورود»؛ بعد دانش‌آموز دوباره `/start` می‌زند.
- **خبر به مدیر:** هر ورود موفق به مدیرها اطلاع داده می‌شود (برای اینکه ببینید یوزرنیم را درست داده‌اید).
- **«🕓 ورود نشده‌ها»:** کسانی که بات را استارت کرده‌اند ولی وارد نشده‌اند (نام و یوزرنیمی که بات دیده) تا غلط‌های تایپی را ببینید.
- **«🆔 فهرست یوزرنیم‌ها»:** وضعیت همه (✔ وارد شده / 🕓 هنوز نه).

⚠️ **یوزرنیم در بله اختیاری است.** دانش‌آموزی که یوزرنیم ندارد باید در تنظیمات پروفایل بله یکی بسازد؛ یا `LOGIN_MODE=both` بگذارید تا کد ۶ رقمی هم قبول شود (کد هر دانش‌آموز هنوز ساخته می‌شود و در «🆔 فهرست یوزرنیم‌ها» دیده می‌شود).

### مهاجرت از نسخه‌ی قبلی
۱. نسخه‌ی تازه را مستقر کنید (دیتابیس خودکار ارتقا می‌یابد؛ چیزی پاک نمی‌شود).
۲. دانش‌آموزانی که وارد بات هستند همان‌طور وارد می‌مانند و یوزرنیمشان خودکار ثبت می‌شود.
۳. برای بقیه از «📝 ثبت گروهی یوزرنیم» استفاده کنید.
۴. اگر می‌خواهید همه دوباره با یوزرنیم تأیید شوند: برای هر نفر «🔓 بازنشانی ورود» را بزنید.

## ویرایش پاسخ تا پایان مهلت
- دانش‌آموز بعد از ارسال، در صفحه‌ی تکلیف (یا «✅ ارسال‌های من») دکمه‌ی **«✏ ویرایش پاسخ»** و «👁 دیدن پاسخ فعلی» را می‌بیند.
- در ویرایش: فایل تازه اضافه می‌کند، فایل‌های اشتباه را با 🗑 حذف می‌کند، یا همه را حذف می‌کند و پاسخ تازه می‌فرستد؛ بعد «ارسال نهایی».
- **هر چند بار بخواهد، تا لحظه‌ی مهلت** (مهلت اصلی یا مهلتی که مدیر برایش تمدید کرده). وضعیت «به‌موقع» حفظ می‌شود.
- تا «ارسال نهایی» نزند، پاسخ قبلی دست‌نخورده می‌ماند؛ «لغو» هم چیزی را عوض نمی‌کند.
- اگر وسط ویرایش مهلت تمام شود و «ارسال نهایی» بزند، تغییر ثبت **نمی‌شود** و پاسخ قبلی حفظ می‌شود.
- بعد از مهلت (حتی در ۲۰ دقیقه‌ی تاخیر مجاز) ویرایش بسته است؛ فقط با «درخواست ارسال مجدد» مدیر.
- فایل‌های نسخه‌های قدیمی خودکار پاک می‌شوند تا دیسک پر نشود. مدیر هنگام دیدن پاسخ، تعداد ویرایش‌ها را می‌بیند.

# بررسی پاسخ‌ها توسط مدیر (به‌روزرسانی)

## ویرایش وضعیت هر تکلیف
مدیر وضعیت هر تکلیف را برای هر دانش‌آموز عوض می‌کند. دو راه:
- صفحه‌ی دانش‌آموز ← **«📋 بررسی تکالیف»** ← تکلیف را بزن.
- صفحه‌ی تکلیف ← **«✏ تغییر وضعیت یک نفر»** (یا هنگام دیدن پاسخ یک نفر «✏ تغییر وضعیت»).

وضعیت‌ها: **✅ ارسال‌شده (به‌موقع)** | **⏰ با تاخیر** | **⚠️ ناقص** | **❌ ارسال‌نشده** | **↩ برگشت به حالت خودکار**.
- می‌شود هر وضعیتی (ناقص، با تاخیر، ارسال‌نشده) را به «ارسال‌شده» تبدیل کرد؛ مثلاً تکلیفی که روی کاغذ تحویل داده شده یا تاخیرِ بخشیده‌شده.
- **ناقص:** مدیر می‌تواند توضیح بنویسد؛ دانش‌آموز پیام می‌گیرد و می‌تواند دوباره بفرستد (وضعیت زمانی ارسال اول حفظ می‌شود). بعد از ارسال مجدد، «ناقص» برداشته می‌شود تا دوباره بررسی شود. ناقص شمارنده را قطع می‌کند و امتیاز تکلیف امتیازی را رد می‌کند.
- وضعیت‌های ویرایش‌شده با ✎ مشخص می‌شوند (بات، اکسل و پنل). هر ویرایش در «فعالیت مدیران» ثبت می‌شود و دانش‌آموز خبر می‌گیرد.

## نشان و امتیاز بعد از تأیید مدیر
- **نشان پشتکار** (۶ تکلیف الزامی پشت‌سرهم و به‌موقع) و **نشان کوشا** (۵ تکلیف اختیاری/امتیازی) «در انتظار تأیید» ساخته می‌شوند. دانش‌آموز تا تأیید مدیر آن‌ها را نمی‌بیند.
- مدیر در «⭐ تأیید نشان و امتیاز» (شمار موردها کنارش نوشته می‌شود) تأیید یا رد می‌کند؛ هر مورد جدا یا «تأیید همه». امتیاز نشان همراه خود نشان تأیید می‌شود.
- اگر مدیر پیش از تأیید یکی از آن تکالیف را «ناقص» کند، نشان در انتظار خودکار پس گرفته می‌شود؛ با درست‌شدن وضعیت دوباره ساخته می‌شود. نشان تأییدشده با ویرایش بعدی حذف نمی‌شود (در «🏅 مدیریت نشان‌ها» دستی حذف کنید).
- رد نشان، آن را حذف و مسدود می‌کند (دوباره خودکار داده نمی‌شود).
- امتیاز نشان پشتکار با `STREAK_POINTS` تنظیم می‌شود (پیش‌فرض ۰)؛ نشان کوشا ۱۰ امتیاز دارد (`EXTRA_STREAK_POINTS`).
- نشان‌های «اولین قدم»، «پیشگام»، «ستاره‌ی امتیازی» و «کنجکاو» فوری‌اند.

# پایه‌ی هفتم (به‌روزرسانی)

| پایه | چه دارد |
|---|---|
| ششم | تکالیف + نشان و امتیاز |
| **هفتم** | **همه‌ی امکانات تکلیف، بدون نشان و امتیاز** |
| نهم | فقط باشگاه کتابخوانی |

- **افزودن:** «👥 دانش‌آموزان ← ➕ افزودن ← پایه‌ی هفتم»، هر خط `نام | @یوزرنیم`.
- **هفتمی‌ها دارند:** تکالیف و مهلت، تاخیر مجاز و تاخیر تا ۲۴ ساعت، ارسال و ویرایش تا مهلت، عذر موجه، تمدید و ارسال مجدد، بررسی وضعیت (ناقص / ارسال‌شده / ...)، بازخورد، یادآوری، پیام همگانی (`پایه‌ی هفتم`)، گزارش، اکسل، ZIP و پنل وب.
- **هفتمی‌ها ندارند:** نشان پشتکار و کوشا، امتیاز تکلیف امتیازی، شمارنده و صف تأیید. منویشان «📈 پیشرفت من» دارد (آمار تکالیف) به‌جای «🏅 نشان‌ها و پیشرفت». در دید مدیر هم «مدیریت نشان‌ها» و «امتیاز» برای آن‌ها نیست.
- **مخاطب تکلیف:** هنگام ساخت تکلیف: «هر دو پایه (ششم و هفتم)» | «فقط ششم» | «فقط هفتم» | «گروه‌های مشخص». **تکالیف قبلی همه فقط برای ششم می‌مانند** (ستون `target_grade` با مقدار ۶ ساخته می‌شود).
- تکلیف امتیازی برای هفتمی‌ها یک تکلیف معمولی است؛ امتیازش فقط برای ششمی‌ها حساب می‌شود.
- جدول نشان‌ها (بات و پنل) فقط پایه‌ی ششم را نشان می‌دهد.
- گزارش‌ها (متن، اکسل، پنل) هر دو پایه را با ستون «پایه» نشان می‌دهند؛ ستون‌های نشان و امتیاز برای هفتم «—» است.
