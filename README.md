# بات تکالیف «مجموعه تربیتی، آموزشی رشد» (اپ بله)

بات ثبت و دریافت تکالیف پایه ششم: دانش‌آموز با کد شخصی وارد می‌شود، تکلیف را می‌بیند و پاسخ را با عکس یا PDF می‌فرستد؛ مدیر مهلت تعیین می‌کند، گزارش می‌گیرد و بازخورد می‌دهد.

## امکانات فاز ۱ تا ۳ (ساخته و آزمایش شده)

| بخش | توضیح |
|---|---|
| ورود | کد ۶ رقمی شخصی؛ قفل ۱۰ دقیقه‌ای بعد از ۵ بار اشتباه؛ بازنشانی کد توسط مدیر |
| تکلیف | عنوان، متن، عکس/فایل ضمیمه، نوع (الزامی / اختیاری / امتیازی)، مخاطب (همه یا گروه‌ها) |
| مهلت | تاریخ شمسی و ساعت ایران؛ تاخیر مجاز ۲۰ دقیقه؛ ارسال با تاخیر تا ۲۴ ساعت با ثبت دقیق «ساعت و دقیقه» تاخیر؛ بعد از ۲۴ ساعت بسته |
| ارسال | چند عکس/PDF + «ارسال نهایی»؛ جایگزینی پاسخ تا قبل از مهلت |
| مدیر | ویرایش، تمدید برای همه یا یک نفر، عذر موجه، درخواست ارسال مجدد (وضعیت زمانی ارسال اول حفظ می‌شود)، لغو تکلیف |
| نشان‌ها | هر ۶ تکلیف الزامی پشت‌سرهم و به‌موقع = یک نشان؛ تاخیر یا ارسال‌نشدن شمارنده را صفر می‌کند؛ عذر موجه نادیده گرفته می‌شود؛ نشان‌های خودکار دیگر (اولین قدم، پیشگام، ستاره‌ی امتیازی، کنجکاو) و نشان دستی |
| گزارش | خلاصه‌ی کلاس، گزارش فردی، اکسل کامل (RTL)، آخرین ارسال‌ها، جدول نشان‌ها |
| دانلود | ZIP همه‌ی پاسخ‌های یک تکلیف یا یک دانش‌آموز |
| ارتباط | پیام همگانی (همه یا گروه)، بازخورد به هر فرد، یادآوری خودکار ۳ ساعت مانده به مهلت |
| ایمنی | پشتیبان روزانه‌ی دیتابیس (۱۴ نسخه)، ثبت همه‌ی کارهای مدیر (audit) |

**فاز ۴ (ساخته شد):** پنل وب فقط‌خواندنی؛ جزئیات در بخش «پنل وب» پایین.

**فازهای بعدی:** اتصال به کارنامه، آزمون تستی.

## راه‌اندازی

### ۱) ساخت بات در بله
در بله با `@botfather` یک بات بسازید و **توکن** را بردارید. عکس و نام بات را همان‌جا بگذارید (لوگوی رشد). توکن را برای هیچ‌کس نفرستید و در چت ننویسید.

### ۲) سرور (لینوکس، اوبونتو)
```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo useradd -m -s /bin/bash rosh
sudo mkdir -p /opt/rosh_bot && sudo chown rosh:rosh /opt/rosh_bot
# فایل‌های پروژه را در /opt/rosh_bot بگذارید، سپس:
sudo -u rosh bash -c 'cd /opt/rosh_bot && python3 -m venv venv && venv/bin/pip install -r requirements.txt'
```
اگر `pip` به PyPI نرسید، از یک mirror ایرانیِ معتبر با گزینه‌ی `-i` استفاده کنید.

### ۳) تنظیمات
```bash
cd /opt/rosh_bot && cp .env.example .env && nano .env     # BALE_TOKEN و ADMIN_IDS
chmod 600 .env
```
شناسه‌ی عددی مدیر: هر کس در بات `/myid` را بفرستد، شناسه‌اش را می‌گیرد. شناسه‌ها را (جدا شده با ویرگول) در `ADMIN_IDS` بگذارید. بعداً هم مدیر جدید از «⚙ مدیران» اضافه می‌شود.

### ۴) اجرا
آزمایش دستی: `venv/bin/python -m app.main`  
اجرای دائمی:
```bash
sudo cp deploy/rosh-bot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now rosh-bot
sudo journalctl -u rosh-bot -f      # دیدن لاگ
```

### ۵) لوگو (اختیاری)
فایل `assets/logo.png` را بگذارید؛ در پیام خوشامدگویی نمایش داده می‌شود.

## اولین استفاده
1. مدیر `/start` می‌زند ← «👥 دانش‌آموزان» ← «➕ افزودن»: اسم‌ها را (هر نفر یک خط، اختیاری `نام | گروه`) می‌فرستد و کدها را می‌گیرد.
2. هر کد را فقط به خود همان دانش‌آموز بدهید.
3. «📝 تکلیف جدید» ← عنوان، متن/عکس، نوع، مخاطب، مهلت ← انتشار.

## پشتیبان‌گیری
همه‌چیز در پوشه‌ی `data/` است: `rosh.db` + `assignments/` + `submissions/`. هر شب یک نسخه از دیتابیس در `data/backups/` ساخته می‌شود؛ پوشه‌ی `data/` را هفتگی جای دیگری هم کپی کنید.

## نکات امنیت و حریم خصوصی
- فقط نام، گروه و شناسه‌ی بله ذخیره می‌شود. پاسخ‌ها فقط برای مدیران قابل مشاهده است.
- کد ورود محرمانه است؛ هر کد فقط روی یک حساب فعال می‌شود.
- فایل `.env` را در هیچ مخزن یا چتی نگذارید.

## آزمایش
```bash
venv/bin/python tests/test_rules.py && venv/bin/python tests/test_flow.py && venv/bin/python tests/test_panel.py
```

## اولین آزمایش با بله‌ی واقعی (چک‌لیست)
این پروژه با بله‌ی جعلی کامل آزمایش شده، اما با سرور واقعی بله روی سرور شما باید یک‌بار چک شود:
1. `/start` و `/myid` جواب می‌دهد؟
2. دکمه‌ها کار می‌کنند و بعد از لمس، پیام ویرایش می‌شود (اگر ویرایش پشتیبانی نشود، خودکار پیام تازه می‌آید).
3. عکس و PDF از دانش‌آموز دریافت و ذخیره می‌شود؟
4. بات عکس تکلیف را برای دانش‌آموز و ZIP/اکسل را برای مدیر می‌فرستد؟
5. اگر هرکدام خطا داد، لاگ (`journalctl`) را برای اصلاح بفرستید.

## اجرای دائمی روی ویندوز (بدون سرور)
- `start_bot.bat` را اجرا کنید: بات را بالا می‌آورد و اگر قطع شد، بعد از ۱۰ ثانیه دوباره راه می‌اندازد.
- برای اجرا با روشن‌شدن سیستم: در Task Scheduler یک Task بسازید (Trigger: At log on، Action: همین فایل).
- خواب سیستم را خاموش کنید: Settings ← System ← Power ← Sleep = Never.
- `backup_data.bat` پوشه‌ی data را در `rosh_backup` کپی می‌کند؛ هفتگی اجرا کنید و نسخه را روی فلش یا Drive هم بگذارید.

## پنل وب فقط‌خواندنی (فاز ۴)

یک وب‌سایت فارسی و راست‌چین برای مدیران که همه‌چیز را **فقط نشان می‌دهد** و هیچ چیزی را تغییر نمی‌دهد.

**صفحه‌ها:** داشبورد (آمار روز، مهلت‌های پیش‌رو، نیازمند پیگیری، وضعیت همه‌ی دانش‌آموزان) | دانش‌آموزان و گزارش کامل هر نفر | تکالیف و وضعیت هر تکلیف با عکس پاسخ‌ها | نشان‌ها | بازخوردها | گزارش فعالیت مدیران | دانلود اکسل کامل و ZIP پاسخ‌ها.

### اجرا (کنار بات)
```
python -m app.panel          # ویندوز: start_panel.bat را اجرا کنید
```
سپس در مرورگر: `http://localhost:8080` . پنل یک فرایند جداست؛ بات هم باید یک‌بار اجرا شده باشد (تا دیتابیس ساخته شود).

### ورود (بدون رمز عبور)
۱. در بات بله: پنل مدیریت ← «🌐 ورود به پنل وب»
۲. کد ۸ رقمی را در صفحه‌ی ورود پنل بزنید. کد ۵ دقیقه اعتبار دارد و فقط یک‌بار قابل استفاده است. نشست ۱۲ ساعت باقی می‌ماند.

### چرا امن است
- پنل دیتابیس را فقط‌خواندنی باز می‌کند (حتی با باگ هم نمی‌تواند چیزی بنویسد) و هر درخواست غیر GET را رد می‌کند.
- کد ورود به‌صورت هش ذخیره می‌شود؛ بعد از ۵ تلاش ناموفق، ۱۰ دقیقه قفل می‌شود.
- کوکی `HttpOnly` و `SameSite=Strict` است؛ فایل‌ها فقط از داخل پوشه‌ی `data` سرو می‌شوند؛ همه‌ی متن‌ها escape می‌شوند.
- به‌صورت پیش‌فرض فقط روی همین سیستم (`127.0.0.1`) گوش می‌دهد.

### قرار دادن روی اینترنت (روی سرور)
فقط با HTTPS. فایل `deploy/Caddyfile.example` را ببینید (Caddy گواهی را خودکار می‌گیرد)، سپس در `.env`:
```
PANEL_URL=https://panel.example.ir
PANEL_SECURE_COOKIE=1
PANEL_TRUST_PROXY=1
```
سرویس دائمی: `deploy/rosh-panel.service` (مثل سرویس بات نصب می‌شود).
فونت: Vazirmatn (مجوز OFL؛ در `assets/`). اگر `assets/logo.png` بگذارید، در هدر پنل نمایش داده می‌شود.

## نصب سریع روی سرور اوبونتو (اسکریپت آماده)
۱. فایل ZIP را روی سرور بگذارید: `scp rosh-bale-bot.zip root@IP:/root/`
۲. روی سرور: `unzip rosh-bale-bot.zip && bash rosh_bot/deploy/install.sh`
۳. توکن بات و شناسه‌ی مدیران را وارد کنید؛ اسکریپت همه‌چیز را نصب و بات را اجرا می‌کند.
۴. بررسی: `systemctl status rosh-bot` و `journalctl -u rosh-bot -f`

### دیدن پنل وب بدون دامنه و HTTPS (تونل SSH)
روی سرور: `systemctl enable --now rosh-panel` ؛ روی کامپیوتر خودتان:
```
ssh -L 8080:127.0.0.1:8080 root@IP
```
و در مرورگر: `http://localhost:8080` (تا وقتی پنجره‌ی SSH باز است کار می‌کند).

### پشتیبان‌گیری از سرور روی کامپیوتر خودتان
`scp -r root@IP:/opt/rosh_bot/data ./rosh_backup`
